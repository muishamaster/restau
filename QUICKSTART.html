// Dans script.js, section CONFIG CONFIG.DELIVERY_FEE = 1000; CONFIG.WHATSAPP_NUMBER = '243977970594'; CONFIG.PAYMENT_PROVIDERS = { ... };

Tester Panier (Debug)

// Dans console du navigateur DEBUG.populateTestCart(); // Remplir panier test DEBUG.showCartState(); // Afficher état DEBUG.clearCache(); // Réinitialiser

🔧 Troubleshooting

QR Code ne s'affiche pas

✓ Vérifier CDN qrcode.js est accessible
✓ Vérifier console pour erreurs
✓ Tester avec URL locale

Panier ne persiste pas

✓ Vérifier localStorage activé
✓ Vérifier pas de erreurs JSON
✓ Tester incognito mode

Paiement ne fonctionne pas

✓ Vérifier numéro WhatsApp
✓ Vérifier montant > 0
✓ Tester sur vrai téléphone

Site lent

✓ Optimiser images
✓ Activer gzip compression
✓ Utiliser CDN
✓ Minifier CSS/JS
